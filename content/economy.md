# 경제 (economy.md)

## 결정 요약
- 자원은 둘: **식량**(이동·회복)과 **골드**(상점·서비스). 화폐 이름은 골드.
- 식량 소모: 새 칸에 들어갈 때마다 **생존 대원 수만큼** (2명이면 2). 식량이 0일 때 이동하면 **생존 대원 전원이 체력 피해**(굶주림, 초기값 3).
- 식량 획득: **전투 보상에서 정수/식량/골드 중 선택**. 보물방·이벤트·상점에서도 얻는다.
- 야영지 회복은 **식량을 소모**한다. 정수 관련 서비스는 골드.
- 상점 품목: **정수, 식량, 정수 제거.** 정수를 제거하면 그 정수의 카드도 함께 사라진다. (카드는 따로 사거나 제거할 수 없다. 체력 치유는 팔지 않는다)
- 상태: 확정 (아래 수치는 초기값 제안, 2-12 밸런스에서 조정)

## 규칙
| 항목 | 내용 | 상태 |
|---|---|---|
| 식량 소모 | 새 칸에 들어갈 때 생존 대원 수만큼. 영구 사망하면 소모가 줄어든다 | 확정 |
| 굶주림 | 식량 0에서 이동하면 생존 대원 전원 체력 피해 (초기값 3). 피해로 쓰러지면 영구 사망 | 확정 |
| 영입과 식량 | 영입 수락은 식량 소모 (초기값 4). 인원이 늘면 칸마다 소모도 늘어난다 | 확정 |
| 식량 획득 | 전투 보상(정수/식량/골드 중 선택), 보물방, 이벤트, 상점 구매 | 확정 |
| 골드 획득 | 전투 보상, 보물방, 이벤트 | 확정 |
| 야영지 회복 | 식량을 쓰면 생존 대원 전원이 최대 체력의 30% 회복 (초기값: 식량 3) | 확정 |
| 정수 제거 | 상점에서 골드로 정수를 없앤다. 장착한 정수는 해제할 수 없고 제거만 가능하다. 제거하면 그 정수의 카드도 함께 사라진다 (덱 압축 수단) | 확정 |
| 카드 구입·제거 | 없다. 카드는 정수로만 얻고, 정수를 제거할 때만 사라진다. 정수를 장착하면 기본 카드가 1장씩 줄고, 제거하면 되살아난다 (`party.md`) | 확정 |
| 체력 치유 | 상점에서는 팔지 않는다. 회복은 야영지에서만 | 확정 |
| 장비 수리 | 야영지에서 한다. 비용(식량·골드 등)은 `equipment.md`에서 정한다 | 미정 |
| 화면 표시 | 지도·전투 화면 위쪽에 식량과 골드를 항상 보여준다 | 제안 |

## 초기값 (모두 제안, 2-12단계에서 조정)
| 항목 | 값 |
|---|---|
| 시작 식량 | 12 |
| 식량 최대치 | 40 |
| 전투 보상 | 식량 +5 / 골드 +20 (강한 적 +40, 보스 +60) 중 정수와 함께 선택 |
| 보물방 | 식량 +8 또는 골드 +40 |
| 상점 식량 | +5당 25골드 |
| 상점 정수 | 등급별 가격: 낮음 50 / 중간 90 / 높음 150 (후보 3개 진열) |
| 정수 제거 | 40골드, 쓸 때마다 +20 |
| 시작 골드 | 0 |

## 메모
- 15칸 기준 칸마다 2~4가 들어 한 판에 약 45가 필요하다. 시작 식량 12 + 전투 보상 선택 + 보물방으로 맞추는 것이 목표이고, 부족하면 굶주림이 압박이 된다.
- 구현 영향: 런 상태에 `food`, `gold` 추가, 저장 형식 변경, 이동 시 소모 처리(`run.js`), 화면 표시, 보상 선택지에 식량·골드 추가, 상점 칸. (2-7단계)
- 글 톤: 예) "식량이 떨어졌다. 굶주림이 몸을 갉는다. (각자 피해 3)"

# 콘텐츠 문서 인덱스

> 2차 플랜 2-0단계에서 영역별로 하나씩 만든다. **새 세션은 이 파일만 먼저 읽고, 지금 단계에 필요한 파일만 열어 본다.** (토큰 절약)
> 상태: 미작성 / 초안 / 확정 / 구현됨(구현된 뒤에는 `data/*.js`가 원본이고 문서는 설계 의도만 남긴다)

## 파일 형식 규칙
- 맨 위에 **"결정 요약" 5줄 이내**. 요약만 읽어도 판단이 되게 쓴다.
- 아래는 표 중심. 논의 과정은 쓰지 않고 **확정 결과와 이유 한 줄**만 쓴다.
- 한 파일이 약 150줄을 넘으면 `events-1.md`, `events-2.md`처럼 나눈다.
- 규칙 자체는 `GAME_DESIGN.md`가 기준이다. 여기에는 목록·수치·문구 같은 **콘텐츠**만 둔다.

| 2 | `party.md` | 시작 2명, 영입 후보 풀, **영입 방법**, 캐릭터 이름·성격 | 확정 | 2-2 |

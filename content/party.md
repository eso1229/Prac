# 파티 (party.md)

## 결정 요약
- 시작: **후보 4명 중 2명을 고른다.** 후보는 런마다 무작위로 만들어지고, 각자 **무작위 낮은 등급 정수 1개**를 들고 있다.
- 능력치는 모두 같다. 직업 없음, 역할은 정수로 정해진다. **개인 서사·배경 없음.**
- 이름은 **런마다 무작위로 조합**한다 (같은 이름이 매번 나오지 않는다).
- 영입: 이벤트방에서 **무작위 1명**이 나타난다. 1막 안에 확정 1회, 4명째는 2막 이후 확률. (최대 4명)
- 상태: 초안 (영입자의 정수, 영입 대가·거절, 이름 생성 방식은 미정)

## 규칙 표
| 항목 | 내용 | 상태 |
|---|---|---|
| 능력치 | 전원 동일 (기본 체력 30 등은 `data/battle_data.js` 기준) | 확정 |
| 개성 | 이름만 다르다. 배경 이야기, 고유 특성, 고유 대사 없음 | 확정 |
| 시작 후보 | 런 시작 때 무작위 4명 생성. 각자 낮은 등급 정수 1개 보유(후보마다 다름) | 확정 |
| 시작 선택 | 후보 4명 중 2명 선택. 고른 이의 정수도 함께 얻는다. 고르지 않은 후보는 이번 런에서 영입 후보가 된다 | 제안 |
| 영입 이벤트 | 이벤트방에서 아직 합류하지 않은 무작위 1명이 나타난다 | 확정 |
| 영입 횟수 | 1막 안에 1회 확정, 4명째는 2막 이후 확률 | 확정 |
| 최대 인원 | 4명. 4명이면 영입 이벤트는 나오지 않는다 | 제안 |
| 영구 사망 | 쓰러진 대원은 돌아오지 않는다. 정수는 보관함으로 돌아온다 (부활의 성소 제외) | 확정 |
| 영입자의 정수 | 미정 | 미정 |
| 영입 대가·거절 | 미정 | 미정 |
| 이름 생성 방식 | 미정 | 미정 |

## 메모
- 정수 등급 시스템은 `essences.md`에서 정한다. 구현 순서상 2-2단계(파티)가 먼저라서, 그때는 지금 있는 정수 3종을 "낮은 등급"으로 임시 취급한다.
- 구현 영향: 지금 코드는 아군 4명이 고정이다 (`data/battle_data.js`). 파티 목록을 런 상태에 넣고 저장 형식(`run.js`)을 바꿔야 한다. (2-2단계)

# 파티 (party.md)

## 결정 요약
- 시작: **무작위 이름의 2명으로 선택 없이 시작**한다. **정수 없이** 시작하며, 모든 대원은 **기본 공격 카드 4장 + 기본 방어 카드 4장**을 가지고 있다.
- 능력치는 모두 같다. 직업 없음, 역할은 정수로 정해진다. **개인 서사·배경 없음.** 캐릭터 선택 화면 없음.
- 이름: **이름 + 별칭** 무작위 조합 (예: "회색 아델"). 런마다 다르고 한 런 안에서 겹치지 않는다.
- 영입: 이벤트방에서 **새로 만들어진 무작위 1명**이 나타나 **수락/거절**을 고른다. 수락하면 **식량을 소모**한다. 영입자는 **막에 따라 다른 개수의 정수**를 들고 합류한다.
- 영입 횟수: 1막 안에 확정 1회, 4명째는 2막 이후 확률. 최대 4명.
- 기본 카드: 정수를 장착할 때마다 **기본 공격 1장 + 기본 방어 1장이 빠지고**(정수 4개면 0장), 제거하면 1장씩 되살아난다. **모든 카드는 사용 위치 제한이 없다.**
- 상태: 확정 (영입자 정수 개수의 구체 수치는 제안. 식량 소모량은 `economy.md`)

## 규칙 표
| 항목 | 내용 | 상태 |
|---|---|---|
| 능력치 | 전원 동일 (기본 체력 30 등은 `data/battle_data.js` 기준) | 확정 |
| 개성 | 이름만 다르다. 배경 이야기, 고유 특성, 고유 대사 없음 | 확정 |
| 시작 | 런 시작 때 무작위 이름의 2명이 자동으로 정해진다. 선택 없음, 정수 없음 | 확정 |
| 기본 카드 | 모든 대원이 기본 공격 4장, 기본 방어 4장을 가진다 (소유 캐릭터는 그 대원). 효과 수치는 `cards.md` | 확정 |
| 카드 사용 위치 | 모든 카드가 사용 위치 제한 없음. 공격 대상 제한만 있다 (근접은 적 맨 앞열만 등). 기본 공격의 대상 제한은 `cards.md`에서 정한다 | 확정 |
| 기본 카드와 정수 | 정수를 1개 장착할 때마다 그 대원의 기본 공격 1장·기본 방어 1장이 빠진다. 정수 4개면 기본 카드 0장. 정수를 1개 제거하면 기본 공격·방어가 1장씩 되살아난다. 정수는 장착은 자유이나 해제할 수 없고 제거(상점)만 가능하다 | 확정 |
| 장착 슬롯 | 대원당 정수 최대 8개 (기본 카드는 4개에서 모두 사라지고, 5~8개째는 추가 카드만 준다) | 확정 |
| 정수당 카드 수 | 제한 없음 (정수마다 1장~4장 이상) | 확정 |
| 첫 정수 | 첫 전투의 승리 보상에서 얻는다 | 제안 |
| 영입 이벤트 | 이벤트방에 새로 만들어진 무작위 1명이 나타난다. 수락/거절 | 확정 |
| 영입 대가 | 수락하면 식량 소모 (소모량은 `economy.md`). 식량이 부족하면 수락할 수 없다 | 확정 |
| 영입자의 정수 | 막에 따라 정수 개수가 다르다. 정수를 든 만큼 기본 카드가 줄어든 상태로 합류 | 확정 |
| 영입자 정수 개수 | 1막 1개 / 2막 2개 / 3막 3개 (초기값). 등급은 `essences.md` | 제안 |
| 영입 횟수 | 1막 안에 1회 확정, 4명째는 2막 이후 확률 | 확정 |
| 최대 인원 | 4명. 4명이면 영입 이벤트는 나오지 않는다 | 확정 |
| 영구 사망 | 쓰러진 대원은 돌아오지 않는다. 정수도 대원에 귀속되어 함께 사라지며 보관함으로 돌아오지 않는다. 대원 데이터는 따로 보관하고, 부활(부활의 성소)하면 그 정수를 그대로 가지고 돌아온다 | 확정 |
| 인원과 식량 | 파티 인원이 늘면 식량 소모가 늘어난다 ("입 하나 더"). 정확한 식은 `economy.md` | 제안 |

## 이름 생성 (`data/names.js`에 둘 목록)
- 형식: **별칭 + 이름** (예: 회색 아델). 이름은 2~3글자, 별칭은 2~4글자 (폰 화면 표시 길이).

## 메모
- 정수 등급 시스템은 `essences.md`에서 정한다.
- 구현 영향: 지금 코드는 아군 4명이 고정이다 (`data/battle_data.js`). 파티 목록을 런 상태에 넣고 저장 형식(`run.js`)을 바꿔야 한다. 영입자 이름은 저장 형식에 포함한다. (2-2단계)
- 글 톤: 영입 이벤트 문구는 `world.md`의 짧고 건조한 서술체 (예: "숨이 붙은 자가 길을 막는다. 같이 가겠다고 한다.")

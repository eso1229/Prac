# 세계관 (world.md)

## 결정 요약
- 제목(가제): **재의 원정**
- 배경: 저주와 역병으로 몰락한 왕국. 죽음이 번졌고, 산 자는 얼마 남지 않았다.
- 이야기: 파티는 **원정대**다. 저주의 근원을 찾아 깊은 곳으로 내려가 파괴한다. (반지 원정대처럼 목적지가 있는 여정, 동료는 도중에 합류한다)
- 정수: **죽은 자의 정수를 빌려 쓰는 힘.** 장착하면 그 죽은 자의 기술(카드)과 특성을 얻는다.
- 런 목표: 3막을 지나 **저주의 근원(최종 보스)** 처치. 근원의 정체는 마지막에 밝혀진다.
- 글 톤: 다크 판타지. **짧고 건조한 서술체.** 전투 로그, NPC 대사, 이벤트 문구, 보상 문구 모두 이 톤.
- 상태: 확정 (왕국 이름과 근원의 정체는 미정)

## 세계 개요
| 항목 | 내용 | 상태 |
|---|---|---|
| 무대 | 저주에 무너진 중세풍 왕국. 폐허, 묘지, 지하 깊은 곳으로 이어진다. | 확정 |
| 사건 | 저주가 퍼져 죽은 자가 일어나고 산 자는 병들었다. 근원은 깊은 곳에 있다. | 확정 |
| 원정대 | 파티. 시작 2명, 도중에 최대 4명까지 합류(방법은 `party.md`). | 확정 |
| 정수 | 죽은 자가 남긴 힘의 조각. 쓰러진 동료의 정수도 원정대에 남는다. | 확정 (아래 설정은 제안) |
| 3막 | 근원에 가까워지는 세 단계. 막마다 보스는 근원의 수하다. 지형은 `terrain.md`. | 확정 |
| 근원의 정체 | 마지막에 밝혀진다. 막마다 단서만 흘린다. 정체 자체는 설계자만 아는 비공개 설정으로 `bosses.md` 작성 때 정한다. | 미정 |
| 왕국 이름 | 필요해질 때 정한다. | 미정 |

- **[제안]** 영구 사망한 동료의 정수가 보관함으로 돌아오는 규칙(1차에서 구현됨)을 설정으로 설명한다: "죽은 자는 힘을 남긴다."

## 글 톤 규칙
- 한 문장은 짧게(폰 화면에서 한 줄 안팎). 감정어, 느낌표, 농담, 현대어 금지.
- 수치는 문장 끝 괄호로 쓴다. 예: (피해 6)
- 설명하지 않고 보여 준다. 결과를 담담하게 적는다.
- NPC 대사도 같은 톤: 짧고 건조한 구어체. 말줄임표는 가끔만. 장황한 독백 금지.
- 이모지는 임시 표시다. 3차 아트 단계에서 아이콘으로 바꾼다.

| 상황 | 예시 |
|---|---|
| 적이 공격 | 해골 병사가 리아를 벤다. (피해 6) |
| 방어 | 해골 병사가 방패를 든다. (방어 6) |
| 아군 쓰러짐 | 토비가 쓰러졌다. 정수만 남았다. |
| 전투 승리 | 움직이는 것은 없다. |
| 보상 | 죽은 자의 정수가 손에 쥐어졌다. |
| 휴식 | 불을 지폈다. 잠깐이나마 숨을 돌렸다. |
| 패배 | 원정은 여기서 끝났다. |
| 클리어 | 저주가 걷혔다. 재만 남았다. |
| NPC | "…아직 숨이 붙어 있군. 같이 가겠다." |

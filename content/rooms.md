# 방과 지도 (rooms.md)

## 결정 요약
- 칸 종류 9가지: 전투, 엘리트, 보스, **야영지, 정비소, 상점, 보물방, 이벤트방, 미지 칸(?)**
- **야영지: 회복만** (식량을 써서 생존 대원 전원 30% 회복). 강화·카드 업그레이드·카드 제거는 없다.
- **정비소(가칭): 장비 착용, 장비 강화, 정수 강화.** 정수 **장착/해제는 지도에서 언제든** 가능하고, 정수 **제거는 상점에서만** 가능하다.
- **보물방:** 보상(정수/식량/골드)을 고르고 상자를 연다. 함정 확률이 있고, 함정이면 체력 피해 또는 **미믹(몬스터) 전투**가 나올 수 있다.
- **미지 칸(?):** 도착해야 종류를 안다. 전투·엘리트·보물방·이벤트·상점 중 하나 (야영지·정비소 제외).
- 지도: 막마다 **확정 배치**(상점, 이벤트, 정비소, 마지막 층 야영지) + 나머지는 확률. 1층은 전투만.
- 상태: 확정 (확률·수치는 초기값 제안, 2-12 밸런스에서 조정)

## 칸 종류
| 종류 | 내용 | 아이콘(임시) | 상태 |
|---|---|---|---|
| 전투 | 일반 적 전투. 승리 보상: 정수/식량/골드 중 선택 (`economy.md`) | ⚔ | 확정 |
| 엘리트 | 강한 적 전투. 보상이 더 크다 | ☠ | 확정 |
| 보스 | 막의 마지막 칸. 쓰러뜨리면 다음 막 | 👑 | 확정 |
| 야영지 | 식량을 써서 생존 대원 전원 최대 체력의 30% 회복. 이 방의 기능은 이것뿐 | 🔥 | 확정 |
| 정비소 | 장비 착용·장비 강화·정수 강화(비용은 골드, `equipment.md`·`essences.md`에서 정함) | 🔨 | 확정 |
| 상점 | 정수·식량 구매, 정수 제거 (`economy.md`) | 💰 | 확정 |
| 보물방 | 아래 "보물방" 참고 | 📦 | 확정 |
| 이벤트방 | 선택지형 사건 (제단, 영입, 부활의 성소, 연전 도전, 수수께끼·조사). 목록은 `events.md` | 📜 | 확정 |
| 미지 칸 | 도착하면 전투·엘리트·보물방·이벤트·상점 중 하나로 정해진다 | ？ | 확정 |

## 규칙 상세
| 항목 | 내용 | 상태 |
|---|---|---|
| 정수 장착/해제 | 지도에서 언제든 가능 (전투 중에는 불가) | 확정 |
| 정수 제거 | 상점에서만 (골드) | 확정 |
| 장비 착용·강화, 정수 강화 | 정비소에서만 | 확정 |
| 보물방 흐름 | ① 열지 말지 고른다 ② 열면 보상 종류(정수/식량/골드)를 고른다 ③ 함정 판정 | 제안 |
| 함정 확률 | 고른 보상에 따라 다르다: 정수 30% / 골드 20% / 식량 15% (더 값진 보상일수록 위험) | 제안 |
| 함정의 결과 | 함정이면 생존 대원 전원 체력 피해(초기값 4) 또는 미믹 전투(함정의 1/3, 초기값). 둘 다 보상은 결국 받는다 (미믹은 이기면) | 제안 |
| 미믹 | 상자로 위장한 적. 전투 후 골드를 추가로 준다. 적 정보는 `enemies.md` | 제안 |
| 미지 칸의 구성 | 전투 40 / 엘리트 10 / 보물방 20 / 이벤트 20 / 상점 10 (%) | 제안 |
| 미지 칸 표시 | 지도에서 "？"로만 보이고, 들어가기 전에는 알 수 없다 | 확정 |

## 지도 생성 규칙
| 항목 | 내용 | 상태 |
|---|---|---|
| 막 구성 | 3막 × (4층 + 보스). 층마다 칸 2~3개, 선으로 이어진 갈래 맵 (현재 구현 그대로) | 확정 |
| 1층 | 전투만 | 확정 |
| 마지막 층(보스 직전) | 야영지가 반드시 1개 이상 | 확정 |
| 막마다 확정 배치 | 상점 1개, 정비소 1개, 이벤트방 1개 이상 (2~4층에 무작위로 배치) | 확정 |
| 1막 영입 | 1막의 이벤트방 하나는 반드시 영입 이벤트 (`party.md`) | 확정 |
| 나머지 칸 가중치(2층 이후) | 전투 8 / 엘리트 3 / 보물방 2 / 이벤트 2 / 미지 칸 3 / 야영지 2 | 제안 |
| 엘리트 제한 | 1층 제외, 막당 최대 2개 | 제안 |

## 메모
- 구현 영향: 지금 코드에는 전투·엘리트·휴식(→야영지로 이름 변경)·보스만 있다. 나머지 칸은 단계별로 추가한다 (정비소·보물방·상점·이벤트·미지 칸: 2-6~2-8단계).
- 지도 생성 규칙이 확정 배치를 요구하므로 `generateMap`(`js/run.js`)의 칸 종류 선택을 바꾼다. 저장된 지도 형식도 달라지므로 저장 형식 버전을 올린다.
- 정비소 이름은 가칭이다. 글 톤에 맞는 이름은 나중에 정한다.
- 글 톤: 예) "상자가 놓여 있다. 자물쇠는 이미 녹슬었다." / "상자가 입을 벌렸다. 이빨이 있다."
